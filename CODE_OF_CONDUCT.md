# Code of Conduct

Radio should be a welcoming place to report bugs, discuss ideas and contribute
code or documentation.

## Expected behavior

- Be respectful, direct and considerate.
- Give useful feedback about the work, not the person.
- Accept corrections and take responsibility for mistakes.
- Respect different backgrounds, viewpoints and levels of experience.
- Credit other people's work and protect private information.

Harassment, discrimination, threats, personal attacks, sexualized conduct,
doxxing, deliberate disruption and repeated unwanted contact are not accepted.

## Scope and enforcement

This policy applies to issues, pull requests, discussions and other project
spaces, as well as public situations where someone officially represents the
project.

Possible violations should be reported privately to the maintainer using the
contact information on [Anthony Sung's GitHub profile](https://github.com/anthonysung).
Do not put sensitive details in a public issue. Reports will be handled as
confidentially as practical.

The maintainer may edit or remove content, close discussions, issue a warning,
temporarily restrict participation or permanently ban someone. The response
will depend on the severity, impact and pattern of the behavior.
