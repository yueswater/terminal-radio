# Security Policy

## Supported versions

Security fixes are made against the current code and the latest published
release. Older releases may be asked to upgrade before a fix is provided.

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability. Use
[GitHub's private vulnerability reporting](https://github.com/anthonysung/radio/security/advisories/new)
and include:

- the affected version or commit;
- the operating system and Python version;
- steps to reproduce the issue;
- the impact you observed;
- a minimal proof of concept, if it can be shared safely;
- any suggested mitigation.

Avoid accessing data that is not yours, disrupting radio streams or services,
or publishing details before a fix is available. The maintainer will review the
report, confirm whether it is in scope and coordinate disclosure when needed.

General bugs and feature requests belong in the public issue tracker.
